# bip39-words

> bip39 · wordlist · derive

[![Rust 1.75+](https://img.shields.io/badge/rust-1.75+-DEA584)](https://www.rust-lang.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Build](https://img.shields.io/badge/build-passing-brightgreen)]()

BIP39 word helper — first address from name/pass.

## Features

- BIP39 path m/44'/0'/0'
- Deterministic digest (stdlib, no crates)
- Vault + account derive
- cargo test covers keys and wallet

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd bip39-words
cargo build --release
./target/release/bip39-words --help
```

## Tests

```bash
cargo test
```

## Project Structure

```
src/main.rs
src/lib.rs
src/digest.rs
src/wallet.rs
```
